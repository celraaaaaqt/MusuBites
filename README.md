# 🍙 MusuGo

**MusuGo** is a food business website created to showcase and promote our Spam Musubi products. Inspired by Japanese cuisine and designed for convenience, MusuGo offers a delicious, affordable, and satisfying snack made with seasoned rice, fried Spam, and wrapped with nori.

The website serves as an online introduction to the MusuGo brand, allowing visitors to learn more about our product, brand, and offerings through a simple, modern, and responsive interface.

---

## 🌐 About MusuGo

MusuGo focuses on making **Spam Musubi** accessible, convenient, and enjoyable for customers.

Our product combines:

* 🍚 Seasoned rice
* 🥩 Fried Spam
* 🌿 Nori (seaweed)
* 🍙 Japanese-inspired preparation

MusuGo is designed for people looking for a **quick, delicious, convenient, and affordable snack**.

## ✨ Features

### 🏠 Landing Page

The landing page introduces visitors to MusuGo and its Spam Musubi product through a visually focused hero section.

### 📱 Responsive Design

The website is designed to work across different screen sizes, including:

* Desktop computers
* Laptops
* Tablets
* Mobile phones

The navigation bar adapts to different screen sizes to provide a better experience on mobile and desktop devices.

The website uses a modern glassmorphism-inspired design, including:

* Backdrop blur
* Subtle borders

The website uses a darkened background image and carefully selected colors to make the content and navigation easier to see while maintaining the MusuGo visual identity.

## 🛠️ Technologies Used

### HTML5

Used to structure the website and its content.

### Tailwind CSS

Used for styling and responsive design.

The project uses Tailwind CSS locally rather than relying on the Tailwind CDN.

### JavaScript

Used to add interactivity and dynamic behavior to the website.

### Vite

Used as the development environment and build tool.

Vite provides:

* Fast development startup
* Hot Module Replacement (HMR)
* Efficient development workflow
* Production builds

### Node.js

Used to manage the project's development environment and dependencies.

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone <repository-url>
```

### 2. Navigate to the Project

```bash
cd musugo
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

Vite will provide a local development URL that you can open in your browser.

---

## 📱 Testing on a Mobile Device

To test the website on a phone while connected to the same network as your computer, start the Vite development server with:

```bash
npm run dev -- --host
```

Then open the network URL provided by Vite on your mobile device.

Make sure both devices are connected to the **same Wi-Fi network**.
